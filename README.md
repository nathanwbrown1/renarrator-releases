# Renarrator releases

Renarrator lets you hear compatible videos in a narrator you choose, with free computer voices, local Kokoro AI voices and optional voices using your own provider keys.

Visit [renarrator.com](https://renarrator.com) for the current release status, [installation and support](https://renarrator.com/help), and [privacy information](https://renarrator.com/privacy).

The preview is a manual Chrome installation. It has not been approved by the Chrome Web Store. Computer voices remain free; email sign-in provides a 30-minute trial of played AI narration. Paid checkout remains unavailable while the merchant application is reviewed.

Download an extension ZIP and its matching corresponding source from [Releases](https://github.com/nathanwbrown1/renarrator-releases/releases). Extract the preview ZIP, open `chrome://extensions`, enable Developer mode, and select **Load unpacked** for the folder containing `manifest.json`. Keep that folder in place. To update, extract the newer preview into the same folder and select **Reload** on the extension card.

Local AI narration supports English, Spanish, Brazilian Portuguese and Hindi. German narration uses computer voices or your own cloud provider key. Cloud providers bill your account separately.
